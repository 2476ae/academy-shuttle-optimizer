# 실사용 안내

학원에서 하원 셔틀을 실제로 운영할 때의 흐름입니다. 원장님이 한 번 준비하면, 선생님과 기사님은 휴대폰으로 각자 화면만 쓰면 됩니다.

## 1. 원장님: 처음 한 번 준비하기

### 서버 켜기

**기사님 휴대폰은 운행 중에 모바일 데이터를 쓰므로, 서버는 인터넷에서 접속할 수 있어야 합니다.** 학원 와이파이 안에서만 열리는 서버로는 길 위의 기사님이 접속할 수 없습니다.

| 방법 | 언제 | 할 일 |
|---|---|---|
| 클라우드에 올리기 (권장) | 실제 운영 | Docker를 지원하는 호스팅에 이 저장소를 올립니다. 아래 "클라우드 배포"를 보세요. |
| 학원 컴퓨터에서 켜기 | 시험 운영, 같은 와이파이 안에서만 쓸 때 | `python -m app`을 실행하고 컴퓨터를 켜 둡니다. |

#### 클라우드 배포

저장소의 `Dockerfile`로 이미지를 만들어 실행합니다.

```bash
docker build -t hawon-shuttle .
docker run -d --name hawon-shuttle -p 8000:8000 \
  -v shuttle-data:/data \
  -e SHUTTLE_ACCESS_CODE=정한-학원-코드 \
  hawon-shuttle
```

- **기록 보관:** `/data`에 하루치 운행 기록이 쌓입니다. 호스팅의 영구 디스크(볼륨)를 `/data`에 연결해야 서버를 다시 켜도 그날 상황이 이어집니다.
- **HTTPS:** 호스팅이 제공하는 HTTPS 주소를 쓰세요. "화면 켜 두기" 같은 기능은 HTTPS에서만 동작합니다.
- **서버는 하나만:** 셔틀 상태를 서버 한 대가 기억하므로 여러 대로 늘리지 마세요.

#### 학원 컴퓨터에서 켜기

```bash
pip install -e .
SHUTTLE_ACCESS_CODE=정한-학원-코드 python -m app
```

같은 와이파이에 있는 휴대폰에서 `http://컴퓨터-IP:8000`으로 접속합니다. 기기 연결 화면이 이 주소를 알아서 채워 줍니다.

### 학원 코드 정하기

`SHUTTLE_ACCESS_CODE`에 정한 코드를 아는 사람만 셔틀을 부르고 볼 수 있습니다. 각 기기에서 처음 한 번만 입력하면 됩니다. 인터넷에 올릴 때는 반드시 정하세요.

### 실제 지명과 이동 시간 넣기 (선택)

[shuttle.local.example.json](../shuttle.local.example.json)을 복사해 `shuttle.local.json`을 만들고, 목적지 이름과 실제로 걸리는 시간을 적은 뒤 `SHUTTLE_CONFIG=shuttle.local.json`으로 지정합니다. 이 파일은 공개 저장소에 올라가지 않습니다.

### 기기 연결하기

처음 화면에서 **기기 연결**을 엽니다. 학원 A·B·C 선생님, 기사님, 현황판용 QR 코드가 나옵니다.

1. 각 휴대폰 카메라로 자기 QR 코드를 찍습니다.
2. 학원 코드를 넣으면 끝입니다. 기기 연결 화면에 코드를 미리 적어 두면 이 단계도 건너뜁니다.
3. 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 2. 선생님: 셔틀 부르기

1. 학생이 끝나 가면 **목적지**와 **인원**을 고릅니다.
2. 바로 나갈 수 있으면 **지금**을 누릅니다. 몇 분 뒤 끝날 것 같으면 **5분 뒤**나 **10분 뒤**를 누르세요. 미리 알릴수록 셔틀이 헛걸음 없이 맞춰 옵니다.
3. 필요하면 **메모**에 학생 이름을 적습니다. 기사님 화면에 보입니다.
4. **셔틀 부르기**를 누르면 셔틀 도착 예정 시각이 바로 나옵니다.
5. 셔틀이 3분 안으로 다가오면 노란 알림이, 도착하면 초록 알림이 진동·소리와 함께 뜹니다. 그때 학생을 내보내세요. 소리는 화면을 한 번 눌러 둔 뒤부터 납니다.

학생 사정이 바뀌면 목록에서 **취소**를 누릅니다. 셔틀이 왔는데 학생이 나가지 않았다면 그 요청은 **미탑승**으로 바뀝니다. 다시 태워야 하면 새로 부르면 됩니다.

## 3. 기사님: 안내대로 운행하기

화면 맨 위에 지금 할 일 한 줄과 버튼 하나가 나옵니다.

| 화면 | 할 일 |
|---|---|
| **출발 → 학원 B·C** | 그곳으로 출발하면서 **출발**을 누릅니다. |
| **다음 정류장 · 학원 B·C** | 도착하면 **도착했어요**를 누릅니다. 내릴 학생은 이때 내린 것으로 기록됩니다. |
| **학원 B·C에서 태우기** | 태울 학생 목록이 나옵니다. 나오지 않은 학생은 체크를 풀고 **탑승 완료**를 누릅니다. |
| **학원 A에서 대기** | 곧 끝나는 학생을 기다리는 중입니다. 시간이 되면 다음 안내가 나옵니다. |

- **하루를 시작할 때:** 셔틀은 학원 A에 있는 것으로 시작합니다. 다른 곳에 있다면 **다른 곳으로 가기 · 위치 바로잡기**에서 정류장을 고르고 **지금 여기 있어요**를 누르세요.
- **안내와 다른 곳으로 가야 할 때:** 같은 메뉴에서 정류장을 고르고 **이곳으로 출발**을 누릅니다. 가는 길에 다른 곳에 도착했다면 **이곳에 도착했어요**를 누릅니다.
- **운전 중:** **음성 안내**와 **화면 켜 두기**를 켜 두면 화면을 보지 않아도 됩니다. 운전 중에는 휴대폰을 조작하지 말고, 정차한 뒤 버튼을 누르세요.

## 4. 원장님·실장님: 현황판

**현황판**에서 셔틀 위치, 기다리는 학생, 운행 계획, 그날의 기록을 봅니다. 오늘 데려다준 학생 수, 평균 대기 시간, 운전 시간도 바로 나옵니다.

## 5. 이럴 때는

| 상황 | 어떻게 되나요 |
|---|---|
| 서버가 꺼졌다 켜졌어요 | 그날의 요청과 운행 기록을 다시 읽어 상황을 그대로 이어 갑니다. |
| 자정이 지났어요 | 새 날로 시작합니다. 전날 기록은 기록 폴더에 남습니다. |
| 셔틀 위치가 틀려요 | 기사님 화면의 **지금 여기 있어요**로 바로잡습니다. |
| 학생이 안 나왔어요 | 기사님이 체크를 풀고 탑승 완료를 누르면 **미탑승**으로 기록되고, 선생님 화면에도 보입니다. |
| 코드를 잊었어요 | 서버 설정의 `SHUTTLE_ACCESS_CODE`를 확인하거나 바꾼 뒤 서버를 다시 켭니다. 코드를 바꾸면 모든 기기에서 새 코드를 다시 입력해야 합니다. |

## 6. 기록과 개인정보

- 하루치 요청과 운행 기록은 서버의 기록 폴더(`SHUTTLE_DATA_DIR`, 기본 `var/`)에 날짜별 파일로 쌓입니다. 메모에 적은 학생 이름도 여기 저장됩니다.
- 기록 폴더는 공개 저장소에 올라가지 않습니다. 오래된 기록이 필요 없으면 `days/` 안의 날짜 파일을 지우면 됩니다.
- 메모에는 이름 정도만 적고, 연락처나 주소는 적지 마세요.
