# 문제 정의

현장 상황과 풀려는 최적화 문제를 정리한 문서입니다. 새로운 정보가 들어올 때마다 고쳐 나갑니다.

- 마지막 수정: 2026-09-23
- 지명 대신 기호를 씁니다. 학원은 A·B·C, 하원 목적지는 ①~④입니다.

## 1. 현장 상황

### 셔틀

- 스타렉스 1대를 학원 A, B, C가 함께 씁니다.
- 좌석 수와 동승 보호자 탑승 여부는 아직 확인 중입니다.

### 학원 (셔틀 타는 곳)

| 학원 | 위치 | 비고 |
|---|---|---|
| A | 북쪽, 목적지 ② 바로 옆 | |
| B | 남동쪽 읍내, 목적지 ④ 가까이 | C와 횡단보도 하나 사이 |
| C | 남동쪽 읍내, 목적지 ④ 가까이 | B와 횡단보도 하나 사이 |

### 하원 목적지

| 목적지 | 종류 | 가까운 학원 |
|---|---|---|
| ① | 마을 | 없음. 서쪽으로 멀리 떨어져 있음 |
| ② | 아파트 단지 | A 바로 옆 |
| ③ | 아파트 단지 | B·C에서 동쪽으로 조금 떨어짐 |
| ④ | 아파트 단지 | B·C 가까이 |

### 위치 관계

![학원과 하원 목적지 배치 개념도](images/sites.svg)

지도에 직접 찍은 위치로 계산한 직선거리 비율입니다. 학원 A와 B·C 사이를 1로 둡니다. 실제 도로 거리와는 다를 수 있습니다.

| 구간 | 직선거리 비율 |
|---|---|
| A ↔ ② | 약 0.15 |
| B·C ↔ ④ | 약 0.25 |
| B·C ↔ ③ | 약 0.8 |
| A ↔ B·C | 1 |
| A ↔ ① | 약 2.7 |
| B·C ↔ ① | 약 3.2 |

정리하면 셔틀이 서는 곳은 세 무리로 나뉩니다.

- **북쪽 무리:** 학원 A, 목적지 ②
- **남동쪽 무리:** 학원 B·C, 목적지 ③·④
- **서쪽 끝:** 목적지 ①

그래서 셔틀 시간은 주로 두 무리 사이를 오가는 데와 ① 왕복에 들 것으로 보입니다. B·C에서 ①에 한 번 다녀오는 거리는 A와 B·C를 한 번 오가는 거리의 약 3배입니다.

## 2. 최적화 문제

### 정할 것

- 운행을 몇 번 할지, 운행마다 어느 학원에서 어떤 학생을 태울지
- 운행마다 학원과 목적지를 들르는 순서
- 운행마다 출발 시각

### 지켜야 할 것

- 한 번에 태우는 인원은 좌석 수를 넘을 수 없습니다.
- 학생은 수업이 끝난 뒤에만 탈 수 있습니다.
- 차가 한 대라서 운행은 하나씩 차례로 합니다.
- (확인 중) 학생 한 명이 차 안에 있는 시간의 상한
- (확인 중) 13세 미만 학생이 타면 동승 보호자가 함께 타야 합니다(도로교통법 제53조). 보호자 인원이 운행을 제약할 수 있습니다.

### 줄이고 싶은 것 (우선순위 확인 중)

- 학생이 수업이 끝나고 집에 도착하기까지 걸리는 시간 (기다리는 시간 + 타고 가는 시간)
- 마지막 학생을 내려 주는 시각 (기사님 퇴근 시각)
- 총 운행 시간과 거리

### 문제 유형

최적화 분야에서는 차량 한 대가 여러 번 운행하는 **다회 운행 차량 경로 문제(multi-trip VRP)** 로 봅니다. 여기에 학생마다 탈 수 있는 시각(수업 끝나는 시각)이 정해져 있다는 조건(release date)이 더해집니다. 서는 곳이 7곳이고 차량이 1대라 규모가 작으므로, 근사해 대신 최적해를 직접 구하는 방법도 검토할 수 있습니다.

## 3. 확인할 것

- [ ] 수업 끝나는 시각: 학원별, 요일별
- [ ] 시간대별 인원: 어느 학원에서 어느 목적지로 몇 명
- [ ] 스타렉스 좌석 수, 동승 보호자 탑승 여부
- [ ] 구간별 이동 시간: 우선 A↔B·C, B·C→①, A→①
- [ ] 지금 운행 순서와 가장 불편한 점
- [ ] 등원(학교 → 학원)도 셔틀로 하는지
- [ ] 아주 가까운 곳(A→②, B·C→④)으로 가는 학생도 셔틀을 타는지
- [ ] 목적지마다 한 곳에서만 내리는지 (특히 ① 마을)
- [ ] B·C 학생을 한 곳에서 한 번에 태울 수 있는지
